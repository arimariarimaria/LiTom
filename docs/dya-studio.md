# DYA Studio 設定ガイド

このファームウェアでは [DYA Studio](https://studio.dya.cormoran.works/) から、マクロ、コンボ、接続先別の基本配列、マウス／スクロールに使うレイヤーを設定できます。追加機能には DYA 独自プロトコルを使います。公式 ZMK Studio だけでは、これらの追加設定はできません。

## 旧ファームウェアからの移行

1. 書き込み前に、現在の配列・ロータリー・トラックボール設定を DYA Studio で控えてください。旧ファームウェアも戻せるよう保存してください。
2. GitHub Actions の成功した `Build ZMK firmware` から `firmware` をダウンロードします。`LiTom_R tom_oled` を含む UF2 は右側、`LiTom_L tom_oled tom_oled_180` を含む UF2 は左側へ書き込みます。両側を同じビルドに揃えてください。
3. 右側を USB 接続して DYA Studio を開きます。この更新ではレイヤー番号と内部の動作 ID 形式が変わります。旧バージョンで保存した配列をそのまま使わず、キーマップの工場出荷配列への復元を行って保存し、接続し直してください。その後、控えた設定を新しいレイヤー番号で反映します。
4. `settings_reset` は Bluetooth ペアリングなども消去する全設定リセット用です。通常の更新には使わず、キーマップの復元で対処できない場合だけ使用し、その後に通常の UF2 を両側へ書き直して再ペアリングしてください。

書き込み後の USB/Bluetooth 入力、OLED、ロータリー、トラックボールの動作は実機で確認してください。ビルド成功は実機での動作確認を代替しません。

旧形式の保存済み動作 ID を読み込めないキーは、起動時にその位置の初期割り当てへ RAM 上で戻します。有効な割り当てや保存領域、Bluetooth ペアリングは消去しません。これは入力を回復するための補助であり、旧レイヤー順序やロータリー設定を移行する処理ではありません。Studio で配列を確認し、上記の移行手順を行ってください。保存するまで補正は永続化されません。

## マウス／スクロールに使うレイヤーを変える

右側を DYA Studio へ接続し、トラックボール設定で対象のプロセッサーを選びます。

- **LiTom Mouse**：`Temporary Layer` を有効にして、`Target Layer` で動かしたときに有効にするレイヤーを選びます。初期値は Mouse (2)、解除までの時間は400msです。
- **LiTom Scroll**：`Active Layers` を特定レイヤーの指定に切り替えて、スクロールとして動かすレイヤーを選びます。初期値は Scroll (3) です。全レイヤーを対象にすると通常の移動もスクロールになるため、通常は対象を1つにします。

スクロール側の XY からスクロールへの変換は有効のままにしてください。マウスとスクロールの対象は別々のレイヤーにします。キーマップでスクロールレイヤーを押して有効にする `MO` / `LT` などのキーも、同じ番号に変更してください。プロセッサーの番号を変えてもキー側の番号は自動では変わりません。

設定が送信された後、10秒以上待ってから再接続し、選択した番号が残ることを確認してください。旧版の `mouse` / `scroll` 設定とは保存名を分けているため、トラックボールの個別調整は新しい2つのプロセッサーで設定し直してください。

一時レイヤーは1回だけ動かした場合も時間で解除されます。動作中に対象番号を変更するか機能を無効にすると、このプロセッサーが有効にした旧レイヤーを解除します。

## Windows と Mac の配列を選ぶ

| 番号 | レイヤー | 用途 |
| --- | --- | --- |
| 0 | Mac | 従来の基本配列 |
| 1 | Windows | Command の位置に Ctrl、Control の位置に Windows キー |
| 2 | Mouse | トラックボールで一時的に有効（400ms） |
| 3 | Scroll | トラックボールのスクロール |
| 4 | Arrow | 従来の矢印・ショートカット |
| 5 | Num | 従来の数値・記号 |
| 6 | Function | F キー |
| 7 | BT | 出力先・Bluetooth 操作 |

接続先の設定画面で、USB と各 Bluetooth プロファイルのデフォルトレイヤーを選びます。Mac のプロファイルには `Mac (0)`、Windows のプロファイルには `Windows (1)` を割り当てて保存してください。未設定時は従来どおり Mac 配列です。

同じ USB ケーブルを両方の OS で使う場合は、OS ごとのレイヤーを `macOS → Mac (0)`、`Windows → Windows (1)` と設定し、USB のデフォルトレイヤーを「OS 検出」にします。Bluetooth でも OS 検出を選べます。OS が正しく判定されない接続先には、レイヤーを直接指定するか Bluetooth プロファイルの OS を手動指定してください。

基本配列の2レイヤーを先頭に保ってください。Mouse などの補助レイヤーを接続先の基本配列に指定することはできません。DYA Studio でレイヤーを並べ替えると、番号で設定する対象も変わるため、基本配列の順序は変更しないでください。

Windows の基本配列のタブ用ロータリーは Ctrl+PageDown / Ctrl+PageUp です。補助レイヤーのショートカットとロータリーは従来の設定を引き継いでいるため、必要に応じて DYA Studio で調整してください。

USB を接続すると USB 出力を優先します。その後に Bluetooth 出力を選択すると、選択した接続先へ入力が送られます。

## マクロを作る

1. マクロ編集画面でマクロを作成し、名前とキー操作を設定します。
2. マクロを保存して、表示されたスロット番号を確認します。
3. キーマップの使いたいキーに `Runtime Macro` を設定し、そのスロット番号を指定してキーマップを保存します。

最大8件、1件あたり符号化データ256バイトまでです。名前と本体を合わせた全マクロの共有容量は1024バイトなので、長いマクロを8件保存できるとは限りません。初期状態のマクロは空です。

## コンボを編集する

コンボ編集画面からキー位置・実行する動作・判定時間を変更し、保存します。16件の枠のうち、以下の7件を初期設定しています。位置は0始まりです。

| スロット | キー位置 | 動作 |
| --- | --- | --- |
| 0 | 6 + 5 | Grave |
| 1 | 6 + 7 | F7 |
| 2 | 8 + 9 | F9 |
| 3 | 9 + 10 | F10 |
| 4 | 10 + 11 | F12 |
| 5 | 4 + 5 | F2 |
| 6 | 12 + 13 | PrintScreen |

従来と同じく判定時間50ms、直前の通常キー入力からの待機時間150ms、全レイヤーで有効です。旧形式の固定コンボは削除しているので二重発火しません。保存済みの変更や削除は初期設定より優先されます。

## 右側 OLED のロック表示

画面下部の修飾キーとレイヤー名の間に、点灯中のロック状態だけを小さく表示します。`C` は Caps Lock、`N` は Num Lock、`S` は Scroll Lock です。PC ごとに状態が異なるため、特定の PC だけで表示されることがあります。旧版の `NLCK` などの長い表示は、BT・プロファイル表示に重ならない固定サイズの表示に変更しました。キー入力や PC のロック状態は変更しません。

## 保存と再接続

各編集画面で保存を実行し、保存後10秒以上待ってから電源を切ってください。再接続後に編集内容が残っていることを確認してください。旧形式の設定ファイルを一括復元する場合は、レイヤー番号や動作 ID の互換性を確認してから使用してください。

## ビルド基盤

ZMK / DYA と追加モジュールは `config/west.yml` のコミットに固定しています。Zephyr 4.1 に合わせて XIAO BLE のボード名、NFC GPIO 設定、PMW3610 ドライバー、ZMK の API 呼び出しを更新しています。GPIO 配置、600 CPI、トラックボールの軸方向、OLED の向きは既存設定を維持しています。
